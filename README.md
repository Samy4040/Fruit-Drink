# FruitDrink Company 🍹

Cloud-native Web-Anwendung für die FruitDrink Company.

## Features
- Drink Konfigurator mit animiertem Mixer
- Küchenartikel Shop mit Warenkorb
- Community Drinks
- Impressionen mit Bildern und Videos

## Technologie-Stack
- Frontend: HTML, CSS, JavaScript (Nginx)
- Backend: Node.js + Express
- Datenbank: MySQL 8.0
- Cache: Redis 7
- Container: Docker + Docker Compose

## Starten
docker compose up --build

Dann: http://localhost:8080
